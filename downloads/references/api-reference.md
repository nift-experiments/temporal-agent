# API reference

> For the complete documentation index, see [llms.txt](https://docs.temporal.io/llms.txt).
> Any documentation page is available as raw Markdown by appending `.md` to its URL.

> Links to API references for the eight Temporal SDKs, the Temporal Server gRPC API, the Temporal CLI, and Temporal Cloud management tools.

API documentation for the Temporal SDKs, Temporal Server, Temporal CLI, and Temporal Cloud.

## SDK API references

- [.NET SDK API](https://dotnet.temporal.io/api/): .NET SDK namespaces, classes, and methods.
- [Go SDK API](https://pkg.go.dev/go.temporal.io/sdk): Go SDK packages, types, and methods on pkg.go.dev.
- [Java SDK API](https://www.javadoc.io/doc/io.temporal/temporal-sdk/latest/index.html): Java SDK classes, interfaces, and annotations on javadoc.io.
- [PHP SDK API](https://php.temporal.io/namespaces/temporal.html): PHP SDK namespaces, classes, and interfaces.
- [Python SDK API](https://python.temporal.io/): Python SDK modules, classes, and functions.
- [Ruby SDK API](https://ruby.temporal.io/): Ruby SDK modules, classes, and methods.
- [Rust SDK API](https://docs.rs/temporalio-sdk/latest/temporalio_sdk/): Rust SDK Workflow and Worker modules, structs, and methods on docs.rs.
- [Rust Client API](https://docs.rs/temporalio-client/latest/temporalio_client/): Rust Temporal Client for starting and managing Workflow Executions, on docs.rs.
- [TypeScript SDK API](https://typescript.temporal.io): TypeScript SDK interfaces, types, and namespaces.

## Server API references

- [Server Frontend API](/self-hosted-guide/server-frontend-api-reference): gRPC API reference used by Client and Worker SDKs to communicate with Temporal Server.
- [Generated gRPC API docs](https://api-docs.temporal.io/): Generated reference for every Temporal Server gRPC service, method, and message.
- [Server API protobuf definitions](https://github.com/temporalio/api): Source protobuf files for the Temporal Server API, for generating clients in any gRPC-supported language.

## CLI references

- [Temporal CLI command reference](/cli/command-reference): Commands and options for the Temporal CLI, including the development server and Workflow management.
- [Temporal CLI cloud command reference](/cli/command-reference/cloud): Commands for the temporal cloud extension, which manages Temporal Cloud accounts, Namespaces, and access.
- [tcld command reference](/cloud/tcld): Commands for tcld, the standalone Temporal Cloud CLI.

## Temporal Cloud API references

- [Cloud Ops API](/ops): HTTP and gRPC API for managing Temporal Cloud Namespaces, Users, Service Accounts, and API keys.
- [Terraform provider](https://registry.terraform.io/providers/temporalio/temporalcloud/latest/docs): Resource and data source reference for managing Temporal Cloud with Terraform.
- [OpenMetrics API](/cloud/metrics/openmetrics/api-reference): Endpoint, authentication, and limits for querying Temporal Cloud metrics in OpenMetrics format.
